# Code of conduct

skyctl adopts the **Apache Software Foundation Code of Conduct**:
https://www.apache.org/foundation/policies/conduct

In short: be open, be empathetic, be welcoming, be collaborative, be
careful in the words you choose, and step down considerately. Harassment,
personal attacks and discriminatory language are not acceptable in any
project space: issues, pull requests, chat, mailing lists or events.

## Reporting

Report conduct concerns privately to the maintainers (see the repository
profile for contact details). Reports are handled confidentially. If the
project joins the ASF, the ASF's reporting guidelines apply, including
contacting the ASF's conduct team directly.
